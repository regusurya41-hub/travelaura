# TravelAura

TravelAura is a cinematic travel discovery app with mood-led destination search, weather-aware theming, AI itinerary generation, saved trips, route previews, and virtual tour embeds.

## Run Locally

```bash
npm install
npm run dev
```

Frontend: `http://localhost:5173`  
Backend: `http://localhost:8080`

Copy `server/.env.example` to `server/.env` for MongoDB, OpenAI, OpenWeather, and Mapbox integration.
